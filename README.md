# Islami App

A Flutter Islamic app that bundles everyday worship content in one place: Quran reading, Hadith, a digital Sebha, radio, and prayer times with Azkar.

## Features

- Onboarding introduction flow
- Quran: full sura list with search, sura details view, and a "most recent" section that remembers where you stopped
- Hadith: browsable hadith collection with details view
- Sebha: digital tasbih counter
- Radio section
- Prayer times and morning/evening Azkar
- Bundled content, works offline

## Tech Stack

- **Flutter** / Dart
- **State management:** Provider
- **Local storage:** SharedPreferences (most-recent tracking)
- **UI:** introduction_screen, carousel_slider, flutter_native_splash, flutter_launcher_icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AhmedWalied26/Islami_App.git
   cd Islami_App
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
